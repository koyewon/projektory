# AI 쌉고수 로드맵 — 디자이너 × AI × 인스타 5만

> 작성일: 2026-10-10
> 목표 3개를 **하나의 시스템**으로 묶는 게 핵심이다.
> **배운다 → 만든다 → 공유한다 → 증명한다.** 공부한 게 콘텐츠가 되고, 콘텐츠가 포트폴리오가 되고, 포트폴리오가 커리어가 된다.

| 목표 | 성공 기준 (12개월) |
|---|---|
| ① AI 실력 | AI로 웹사이트·프로토타입·자동화를 혼자서 처음부터 끝까지 만들어 배포할 수 있다 |
| ② 인스타 | 팔로워 50,000 + 저장/공유율이 높은 계정 + 뉴스레터·커뮤니티 같은 자체 채널 |
| ③ 커리어 | 대기업·IT 기업이 원하는 "AI로 일하는 디자이너"임을 결과물로 증명할 수 있다 |

## 0. 지금 놓치고 있을 가능성이 큰 것 (먼저 읽기)

1. **"AI 정보 계정"은 이미 레드오션이다.** "이번 주 AI 뉴스 TOP5" 같은 계정은 수백 개가 있고, 뉴스는 누가 먼저 올리느냐 싸움이라 지치기 쉽다.
   → 정보가 아니라 **"디자이너가 AI로 실제로 만드는 과정"**으로 차별화해야 한다. 내 결과물은 남이 복붙할 수 없다.
2. **인스타는 지금 '원본성'과 '공유(DM 보내기)'를 밀어준다.** 남의 콘텐츠를 재가공하거나 AI가 찍어낸 듯한 이미지/글은 추천이 잘 안 된다. 내 얼굴·목소리·화면 녹화·작업물 같은 **사람 냄새**가 경쟁력이다.
3. **팔로워보다 '저장·공유'가 먼저다.** 5만은 결과이고, 실제로 관리할 숫자는 게시물당 **저장 수, 공유 수, 시청 완료율**이다.
4. **인스타 밖에 자기 채널이 없다.** 알고리즘이 바뀌면 끝이다. 처음부터 **웹사이트(이 `projektory` 레포)와 뉴스레터**로 사람을 모아야 한다.
5. **"배우고 나서 올려야지"는 함정이다.** 쌉고수가 될 때까지 기다리지 말고, **배우는 과정 자체를 공개**하는 게 오히려 공감을 받는다 ("디자이너가 코딩 0에서 AI로 사이트 만드는 100일").
6. **회사 규정을 확인하라.** 겸업·SNS 활동 규정, 회사 작업물이나 내부 툴 화면 노출 금지, 사내 데이터를 외부 AI에 넣는 문제. 대기업은 이 부분에 특히 엄격하다.
7. **저작권·초상권.** AI 생성 이미지의 상업적 사용 조건, 남의 디자인/레퍼런스를 그대로 쓰는 문제, 툴별 라이선스. "출처 표기 + 직접 만든 결과물" 원칙을 지키자.
8. **번아웃.** 5만은 마라톤이다. 처음부터 **주 3회 이하로 지속 가능한 루틴**과 템플릿을 만들어야 한다.

## 1. AI 실력 로드맵 — "디자이너 출신 AI 빌더"

### 1-1. 꼭 갖춰야 할 역량 6가지

| # | 역량 | 구체적으로 할 수 있어야 하는 것 |
|---|---|---|
| 1 | **프롬프트/컨텍스트 설계** | 역할·목표·제약·예시·출력 형식을 구조화해서 쓰기. 같은 작업을 툴 3개에서 비교해 보기 |
| 2 | **AI 디자인 워크플로** | 리서치 → 무드보드 → 시안 → 에셋 생성 → 다듬기 전 과정에 AI 넣기 (Figma AI, Firefly/Photoshop 생성형 기능, Midjourney 등) |
| 3 | **AI 웹 제작 (바이브 코딩)** | 노코드 AI 빌더 → AI 코딩 에이전트 → 배포까지. 아래 1-2 참고 |
| 4 | **기초 웹 지식** | HTML/CSS/JS 구조, 반응형, Git, 배포, 도메인. *AI가 짜준 코드를 읽고 고칠 수 있는 수준* |
| 5 | **자동화/에이전트** | 반복 업무를 AI + 자동화 툴(Zapier/Make/n8n, MCP 연결)로 없애기 |
| 6 | **AI 활용 판단력** | 보안·저작권·환각 검증, "이건 AI 쓰면 안 되는 일" 구분하기. 대기업 면접에서 특히 본다 |

### 1-2. AI 웹사이트 제작 단계 (레벨업 순서)

| 레벨 | 툴 예시 | 목표 결과물 |
|---|---|---|
| Lv1 노코드 AI | Framer AI, Wix/WordPress AI, Relume | 1시간 안에 랜딩 페이지 하나 |
| Lv2 AI 앱 빌더 | Lovable, v0, Bolt, Figma Make | 로그인·DB 붙은 작은 웹앱 하나 |
| Lv3 디자인→코드 | Figma + MCP(Dev Mode) + AI 에디터 | 내 Figma 시안을 그대로 코드로 |
| Lv4 AI 코딩 에이전트 | Claude Code, Cursor 등 | Git 레포에서 직접 기능 추가·배포 |
| Lv5 배포·운영 | GitHub Pages / Vercel / Netlify, 도메인, 분석 | 실서비스 운영 + 방문자 데이터 보기 |

> 이 `projektory` 레포가 Lv4~5 연습장이다. 지금의 HTML/CSS/JS 연습 페이지를 **"내 AI 작업물 포트폴리오 + 인스타 링크 허브"**로 키우자.

### 1-3. 12주 학습 커리큘럼 (주 6~8시간 기준)

| 주차 | 배우기 | 만들기 (= 그대로 콘텐츠가 됨) |
|---|---|---|
| 1 | LLM 3종 비교, 프롬프트 구조 | "디자이너용 프롬프트 템플릿 10개" |
| 2 | 이미지 생성/편집 AI | 같은 브리프로 툴 3개 비교 |
| 3 | Figma AI 기능, 플러그인 | AI로 와이어프레임 → 시안 30분 컷 |
| 4 | Lv1 노코드 AI 빌더 | 랜딩 페이지 1시간 챌린지 |
| 5 | HTML/CSS 기본 (AI에게 설명 듣기) | AI가 짠 코드 해부 영상 |
| 6 | Lv2 Lovable/v0 | 작은 웹앱 (예: 색상 팔레트 생성기) |
| 7 | Git/GitHub, 배포 | projektory 포트폴리오 리뉴얼 & 배포 |
| 8 | Lv3 Figma → 코드 | 내 시안 → 실제 사이트 변환 과정 |
| 9 | Lv4 AI 코딩 에이전트 | 사이트에 기능 추가 (다크모드, 폼 등) |
| 10 | 자동화 (n8n/Make + AI) | "인스타 콘텐츠 리서치 자동화" 직접 구축 |
| 11 | AI 영상/모션 | 릴스 제작 워크플로 자동화 |
| 12 | 회고 + 케이스 스터디 정리 | "12주 만에 디자이너가 AI 빌더 된 과정" 시리즈 |

## 2. 한국 대기업·IT 기업이 원하는 AI 역량

2026년 채용 시장에서는 **"AI를 아느냐"가 아니라 "AI로 무엇을 해냈느냐"**를 본다. 전문가 조사에서도 *AI 이해·활용 능력 검증*이 채용 핵심 트렌드로 꼽혔고, 면접에서 "AI와 함께 무엇을 할 수 있나요?"가 단골 질문이 되었다. 주요 그룹은 사내 LLM을 운영한다(삼성 Gauss, LG EXAONE, 네이버 HyperCLOVA X, SK·KT 등).

### 디자이너에게 기대하는 것

| 기대 역량 | 증명 방법 |
|---|---|
| AI로 **속도·생산성** 올리기 | "시안 작업 3일 → 1일" 같은 **Before/After 수치** |
| **AI로 프로토타입** 바로 만들기 | 정적 시안이 아니라 클릭되는 프로토타입 링크 |
| **AI 서비스 UX** 설계 | 챗봇·에이전트 화면, 프롬프트 입력 UX, 오류/환각 상태 디자인 |
| 개발자·기획자와 **AI로 협업** | 디자인 시스템 토큰, Figma→코드 연결 경험 |
| **보안·윤리 감각** | 사내 데이터 외부 유출 금지, 저작권, AI 결과물 검수 기준 |
| **업무 자동화 제안** | 팀 반복 업무를 자동화해 본 사례 1개 |

### 커리어용 체크리스트
- [ ] 포트폴리오에 **AI 활용 케이스 스터디 3개** (문제 → AI 활용 과정 → 수치 결과)
- [ ] 배포된 **웹사이트/웹앱 2개 이상** (직접 만든 것)
- [ ] 자동화 워크플로 1개 (스크린 녹화 포함)
- [ ] 이력서에 "AI 툴 이름 나열" 대신 **"AI로 무엇을 몇 % 개선"**으로 작성
- [ ] 관련 자격/교육 (선택): 사내 AI 교육 수료, 기업 AI 활용 자격증 등은 *결과물을 대신하진 못하므로* 보조로만
- [ ] 인스타 계정 자체를 **"AI 실무 역량의 공개 증거"**로 활용 (단, 회사 규정 확인 후)

> 참고: 공개된 대기업 디자이너 공고를 직접 확인하자. 삼성·LG·현대차·SK·네이버·카카오·토스의 프로덕트/UX 디자이너 공고에서 "AI" 키워드를 모아 표로 만들면 그 자체로 좋은 콘텐츠다.

## 3. 인스타그램 운영 전략

### 3-1. 포지셔닝 (한 줄)

> **"AI로 직접 만드는 디자이너 — 따라 하면 나도 만들 수 있는 AI 활용법"**

- 타깃 1순위: 2030 디자이너·기획자·마케터 (실무에 AI 쓰고 싶은 직장인)
- 타깃 2순위: 내 사이트/브랜드를 갖고 싶은 비개발자 (1인 사업자, 프리랜서, 학생)
- 차별점: 정보 전달자가 아니라 **실제로 만드는 사람**. 디자이너 감각으로 "예쁘게" 만든다.

계정명·프로필 체크: 이름에 키워드(예: `OO | AI 디자인·웹 제작`), 프로필 한 줄에 "무엇을 얻는지", 링크는 projektory 사이트(링크 허브)로.

### 3-2. 콘텐츠 기둥 4개 (비율)

| 기둥 | 비율 | 예시 | 노리는 지표 |
|---|---|---|---|
| **AI 실전 활용법** (튜토리얼) | 40% | "이 프롬프트로 무드보드 5분 완성", "Figma에서 꼭 써야 할 AI 기능 5개" | 저장 |
| **AI로 웹사이트 만들기** (과정 공개) | 30% | "코딩 0으로 포트폴리오 사이트 만들기 EP.1~10", 타임랩스 | 팔로우 |
| **툴 비교/리뷰** | 20% | "같은 프롬프트, 툴 3개 결과 비교" | 공유(DM) |
| **커리어·인사이트** | 10% | "대기업 디자이너 공고에서 AI 요구사항 분석", 내 실패담 | 댓글·신뢰 |

### 3-3. 포맷 & 빈도

- **릴스 (주 2~3개)**: 신규 유입 담당. 첫 1~2초에 결과물부터 보여주기 ("이 사이트, 코딩 없이 30분 만에 만들었어요"). 화면 녹화 + 내 목소리/자막. 15~40초.
- **캐러셀 (주 1~2개)**: 저장 담당. 7~10장, 1장 = 후킹 제목, 마지막 장 = "저장하고 따라 해보세요" + 다음 편 예고. **디자이너의 강점이 가장 잘 보이는 포맷** — 템플릿을 만들어 일관된 비주얼로.
- **스토리 (매일 가볍게)**: 작업 중인 화면, 투표, 질문 박스 → 다음 콘텐츠 아이디어 수집.
- **시리즈화**: "EP.1, EP.2…"로 묶으면 팔로우 이유가 생긴다.
- 새 포맷/후킹은 **시험용 릴스(Trial Reels)** 기능으로 비팔로워에게 먼저 테스트.

### 3-4. 성장 단계별 전략

| 단계 | 팔로워 | 기간(예상) | 집중할 것 |
|---|---|---|---|
| 1 | 0 → 1천 | 1~3개월 | 30개 게시물로 실험. 어떤 주제가 저장/공유되는지 찾기. 같은 분야 계정에 진심 담긴 댓글 |
| 2 | 1천 → 1만 | 3~8개월 | 잘 된 주제를 **시리즈화**. 무료 자료(프롬프트 모음, 템플릿)로 "댓글 남기면 DM" 이벤트 → 뉴스레터 수집. 비슷한 규모 계정과 협업(Collab 게시물) |
| 3 | 1만 → 5만 | 8~18개월 | 대표 시리즈 2~3개 고정. 무료 라이브/워크숍, 협업 확대, 스레드·유튜브 쇼츠로 재활용. 첫 수익화 |

> 현실적인 이야기: 5만은 보통 12~24개월 단위 목표다. **바이럴 1~2개**가 단계를 건너뛰게 해주는데, 그건 꾸준히 올린 수십 개 중에서 나온다.

### 3-5. 매주 봐야 할 숫자

| 지표 | 의미 | 목표 감각 |
|---|---|---|
| 저장 수 / 도달 | 쓸모 있는 콘텐츠인가 | 캐러셀은 저장이 좋아요보다 많으면 성공 |
| 공유(보내기) 수 | 남에게 추천할 만한가 | 알고리즘 확산의 핵심 |
| 릴스 3초 유지율 / 평균 시청 시간 | 후킹이 먹혔나 | 첫 장면 수정이 가장 효과 큼 |
| 비팔로워 도달 비율 | 새 사람에게 퍼지고 있나 | 성장기에는 50% 이상 |
| 프로필 방문 → 팔로우 전환 | 프로필이 설득력 있나 | 낮으면 프로필·고정 게시물 수정 |
| 링크 클릭 / 뉴스레터 가입 | 자체 채널로 옮기고 있나 | 매주 증가 |

### 3-6. 주간 루틴 (지속 가능 버전, 주 7~10시간)

| 요일 | 할 일 | 시간 |
|---|---|---|
| 월 | 학습 + 작업 (이번 주 주제 실제로 해보기, 화면 녹화 켜두기) | 2h |
| 화 | 릴스 1 편집·업로드 | 1h |
| 수 | 캐러셀 1 제작 (템플릿 활용) | 1.5h |
| 목 | 학습 + 작업 계속 | 1.5h |
| 금 | 릴스 2 업로드, 댓글·DM 답장 | 1h |
| 토 | 주간 지표 확인 → 다음 주 주제 3개 정하기 | 0.5h |
| 일 | 쉬기 (중요) | — |

### 3-7. AI로 운영 자체를 자동화하기 (그리고 그걸 또 콘텐츠로)
- 주제 리서치: AI에게 "이번 주 디자이너가 관심 가질 AI 업데이트" 요약 요청 → **반드시 원문 확인**
- 대본: 내가 작업하며 말한 녹음 → AI로 대본·자막 정리 (내 말투 유지)
- 캐러셀: Figma/Canva 템플릿 + AI로 문구 다듬기
- 재활용: 릴스 → 스레드 글 → 뉴스레터 → 블로그(사이트) 한 번에 변환
- ⚠️ 글/이미지 전체를 AI로 찍어내지 말 것. **원본성과 사람 냄새가 알고리즘에서도, 팔로워에게도 핵심.**

## 4. 수익화 & 자체 채널 (5만 전에 준비)

1. **링크 허브 = projektory 사이트**: 포트폴리오 + 무료 자료 + 뉴스레터 신청
2. **뉴스레터** (스티비, 메일리, Substack 등): 1천 팔로워부터 시작
3. **무료 리드 마그넷**: "디자이너용 AI 프롬프트 50", "AI 웹사이트 제작 체크리스트"
4. **수익 단계** (1만 이후 검토): 템플릿·전자책 판매 → 원데이 클래스/특강 → 기업 AI 교육 → 브랜드 협찬 (AI 툴사). **협찬은 반드시 광고 표기.**
5. 회사 겸업 규정에 맞춰 진행
