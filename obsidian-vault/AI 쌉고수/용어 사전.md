# 📖 용어 사전

[[AI 성장 로드맵]]과 [[Git 기초 - 커밋 푸시 PR]]에 나오는 어려운 말 모음. 모르는 말 생기면 여기에 계속 추가하기!

## 🤖 AI 관련

| 용어 | 쉬운 뜻 |
|---|---|
| **LLM** (Large Language Model, 대형 언어 모델) | ChatGPT·Claude·Gemini 같은 대화형 AI의 "두뇌" 엔진 |
| **프롬프트** (prompt) | AI에게 주는 지시문/질문 |
| **컨텍스트** (context) | AI에게 같이 주는 배경 정보 (자료, 예시, 내 상황). 많고 정확할수록 결과가 좋아짐 |
| **환각** (hallucination) | AI가 사실이 아닌 걸 그럴듯하게 말하는 것. 그래서 원문 확인 필수 |
| **생성형 AI** | 글·이미지·영상·코드를 새로 만들어내는 AI |
| **바이브 코딩** (vibe coding) | 코드를 직접 짜지 않고 AI에게 말로 "이렇게 만들어줘" 시켜서 만드는 방식 |
| **노코드** (no-code) | 코드 없이 클릭·드래그·말로 만드는 툴 (Framer, Wix 등) |
| **AI 앱 빌더** | 말로 설명하면 앱/웹사이트를 통째로 만들어주는 서비스 (Lovable, v0, Bolt) |
| **AI 에이전트** (agent) | 한 번 대답하고 끝이 아니라, 여러 단계를 스스로 계획하고 실행하는 AI (예: 파일 읽고 → 고치고 → 저장) |
| **AI 코딩 에이전트** | 코드를 직접 읽고 고치고 커밋까지 하는 AI (Claude Code, Cursor) |
| **MCP** (Model Context Protocol) | AI가 다른 앱(Figma, Notion, GitHub 등)을 직접 쓸 수 있게 연결해주는 표준 규격. "AI용 USB 포트" 같은 것 |
| **자동화 툴** (Zapier / Make / n8n) | "A 앱에서 이런 일이 생기면 B 앱에서 저걸 해라"를 자동으로 연결해주는 서비스 |
| **워크플로** (workflow) | 일하는 순서/흐름 |
| **사내 LLM** | 회사 안에서만 쓰는 자체 AI (보안 때문에). 삼성 Gauss, LG EXAONE, 네이버 HyperCLOVA X 등 |

## 💻 웹 제작 관련

| 용어 | 쉬운 뜻 |
|---|---|
| **HTML** | 웹페이지의 뼈대/구조 (제목, 문단, 이미지 자리) |
| **CSS** | 웹페이지의 디자인 (색, 글꼴, 배치) |
| **JavaScript (JS)** | 웹페이지의 동작 (클릭하면 열리기, 애니메이션) |
| **반응형** (responsive) | 폰·태블릿·PC 화면 크기에 맞춰 레이아웃이 알아서 바뀌는 것 |
| **랜딩 페이지** | 소개·홍보용 한 장짜리 웹페이지 |
| **웹앱** | 로그인·저장 등 기능이 있는 웹사이트 (단순 소개 페이지보다 한 단계 위) |
| **DB** (데이터베이스) | 회원 정보·글 같은 데이터를 저장하는 곳 |
| **배포** (deploy) | 내가 만든 사이트를 인터넷에 공개해서 누구나 접속하게 하는 것 |
| **도메인** | 사이트 주소 (예: projektory.com) |
| **GitHub Pages / Vercel / Netlify** | 사이트를 무료(또는 저렴하게) 인터넷에 공개해주는 서비스 |
| **프로토타입** | 실제처럼 클릭해볼 수 있는 시안 |
| **와이어프레임** | 색·이미지 없이 배치만 잡은 뼈대 화면 |
| **Figma Dev Mode** | 개발자가 디자인을 코드로 옮길 때 보는 Figma 모드 |
| **디자인 시스템 / 토큰** | 색·글꼴·간격 등을 이름 붙여 정해둔 규칙. 토큰 = 그 값 하나하나 (예: `primary-blue = #2B6BFF`) |
| **UX** (사용자 경험) | 사용자가 서비스를 쓸 때 느끼는 편함·흐름 전체 |
| **Git / GitHub / 커밋 / 푸시 / PR** | → [[Git 기초 - 커밋 푸시 PR]] 참고 |

## 📱 인스타 / 마케팅 관련

| 용어 | 쉬운 뜻 |
|---|---|
| **알고리즘** | 인스타가 누구에게 어떤 게시물을 보여줄지 정하는 규칙 |
| **도달** (reach) | 내 게시물을 본 사람 수 (중복 제외) |
| **비팔로워 도달** | 나를 팔로우 안 한 사람에게 보여진 비율. 높을수록 퍼지는 중 |
| **저장** | 북마크. "나중에 또 볼래" = 쓸모 있다는 신호 |
| **공유 / 보내기** | DM으로 친구에게 보내기. 알고리즘이 매우 중요하게 본다고 알려짐 |
| **시청 완료율 / 유지율** | 영상을 끝까지(또는 3초 이상) 본 비율 |
| **릴스** | 짧은 세로 영상 |
| **캐러셀** | 옆으로 넘기는 여러 장 이미지 게시물 |
| **스토리** | 24시간 뒤 사라지는 게시물 |
| **시험용 릴스** (Trial Reels) | 팔로워에게 안 보여주고 모르는 사람에게 먼저 테스트하는 기능 |
| **콜라보 게시물** (Collab) | 두 계정이 공동으로 올려서 양쪽 팔로워 모두에게 보이는 게시물 |
| **후킹** (hook) | 처음 1~2초 / 첫 장에서 시선을 붙잡는 장치 |
| **CTA** (Call To Action) | "저장하세요", "댓글 남겨주세요" 같은 행동 유도 문구 |
| **원본성** (originality) | 남의 것 재가공이 아닌 직접 만든 콘텐츠인지 |
| **바이럴** | 갑자기 크게 퍼지는 것 |
| **포지셔닝** | "나는 어떤 사람이다"를 한 줄로 정해서 다른 계정과 구분되게 하는 것 |
| **콘텐츠 기둥** (pillar) | 계정이 다루는 큰 주제 3~5개 |
| **레드오션** | 경쟁자가 너무 많은 시장 |
| **리드 마그넷** (lead magnet) | 무료 자료(템플릿, 체크리스트)를 주고 이메일 등 연락처를 받는 방법 |
| **뉴스레터** | 구독자에게 정기적으로 보내는 이메일 소식지 |
| **링크 허브** | 인스타 프로필 링크 하나로 내 모든 걸(포트폴리오, 자료, 뉴스레터) 보여주는 페이지 |
| **프로페셔널 / 크리에이터 계정** | 인사이트(통계)를 볼 수 있는 인스타 계정 유형. 무료로 전환 가능 |

## 💼 커리어 관련

| 용어 | 쉬운 뜻 |
|---|---|
| **포트폴리오** | 내 작업 결과물 모음 |
| **케이스 스터디** | 작업 하나를 "문제 → 과정 → 결과(수치)" 순서로 정리한 글 |
| **Before/After 수치** | AI 쓰기 전/후 비교 숫자 (예: 3일 → 1일) |
| **겸업 규정** | 회사 다니면서 다른 일(부업·SNS 수익 활동)을 해도 되는지에 대한 회사 규칙 |
| **AI 빌더** | AI를 써서 직접 뭔가를 만들어내는 사람 |
