# 🚀 AI 성장 로드맵 — 디자이너 × AI × 인스타 5만

> [!summary] 핵심
> 목표 3개(AI 실력·인스타·커리어)를 **하나의 시스템**으로 묶기.
> **배운다 → 만든다 → 공유한다 → 증명한다.**
> 어려운 말은 괄호로 풀었고, 더 궁금하면 [[용어 사전]] 참고!

---

## 0. 놓치고 있을 가능성이 큰 것 ⚠️

1. **"AI 뉴스 정리 계정"은 레드오션**(경쟁자가 너무 많은 시장). 뉴스는 누가 먼저 올리느냐 싸움이라 지침.
   → 정보 전달자 말고 **"디자이너가 AI로 실제로 만드는 과정"**으로 차별화. 내 결과물은 아무도 복붙 못 함.
2. **인스타는 원본성**(직접 만든 오리지널 콘텐츠)과 **공유**(DM으로 친구에게 보내기)를 밀어주는 것으로 알려짐. AI로 찍어낸 듯한 글·이미지는 추천(=모르는 사람 피드에 뜨기)이 잘 안 됨. 내 얼굴·목소리·화면 녹화 같은 **사람 냄새**가 무기.
   *(업계 분석 기준이고 인스타 공식 발표는 아님)*
3. **팔로워 수보다 저장·공유가 먼저.** 5만은 결과고, 실제로 관리할 건 게시물별 **저장 수, 공유 수, 시청 완료율**(영상을 끝까지 본 비율).
4. **인스타 밖에 내 채널이 없음.** 알고리즘(인스타가 누구에게 뭘 보여줄지 정하는 규칙)이 바뀌면 끝. 처음부터 **웹사이트(projektory)와 뉴스레터**(구독자에게 보내는 이메일 소식지)로 사람을 모으기.
5. **"고수 되면 올려야지"는 함정.** 배우는 과정 자체가 콘텐츠. ("코딩 0 디자이너가 AI로 사이트 만드는 100일")
6. **회사 규정 확인.** 겸업 규정(회사 다니면서 부업 가능한지), 회사 작업물·사내 툴 화면 노출 금지, 사내 데이터를 외부 AI에 넣는 문제. 대기업은 특히 엄격.
7. **저작권·초상권.** AI 이미지의 상업적 사용(돈 버는 데 써도 되는지) 조건, 남의 디자인 베끼기 문제. "출처 표기 + 직접 만든 결과물" 원칙.
8. **번아웃 주의.** 주 3회 이하로 오래 갈 수 있는 루틴 + 템플릿 먼저 만들기.

## 1. AI 실력 로드맵 — "디자이너 출신 AI 빌더"(AI로 직접 만드는 사람)

### 1-1. 꼭 갖춰야 할 역량 6가지

| # | 역량 | 구체적으로 할 수 있어야 하는 것 |
|---|---|---|
| 1 | **프롬프트/컨텍스트 설계** (AI에게 일 시키는 지시문 + 배경 정보 잘 주기) | 역할·목표·제약·예시·출력 형식을 나눠서 쓰기. 같은 일을 AI 툴 3개에 시켜서 비교 |
| 2 | **AI 디자인 워크플로**(작업 흐름) | 리서치 → 무드보드 → 시안 → 에셋(이미지·아이콘 등 재료) 생성 → 다듬기에 AI 넣기 (Figma AI, Adobe Firefly, Midjourney 등) |
| 3 | **AI 웹 제작 (바이브 코딩** = 코드를 직접 안 짜고 AI에게 말로 시켜서 만드는 방식) | 아래 1-2 레벨 참고 |
| 4 | **기초 웹 지식** | HTML(구조)/CSS(디자인)/JS(동작), 반응형(폰·PC 화면 크기에 맞게 바뀌는 것), Git([[Git 기초 - 커밋 푸시 PR]]), 배포(인터넷에 공개), 도메인(사이트 주소). *AI가 짠 코드를 읽고 고칠 수 있는 수준* |
| 5 | **자동화/에이전트** (AI가 여러 단계를 스스로 처리하게 하는 것) | 반복 업무를 AI + 자동화 툴(Zapier/Make/n8n — 앱끼리 자동 연결해주는 서비스, MCP — AI가 다른 앱을 쓸 수 있게 연결하는 표준)로 없애기 |
| 6 | **AI 활용 판단력** | 보안·저작권·환각(AI가 그럴듯한 거짓말 하는 것) 검증, "AI 쓰면 안 되는 일" 구분. 대기업 면접에서 특히 봄 |

### 1-2. AI 웹사이트 제작 레벨 (순서대로 레벨업)

| 레벨 | 툴 예시 | 목표 결과물 |
|---|---|---|
| Lv1 노코드 AI (코드 없이 클릭·말로 만드는 툴) | Framer AI, Wix/WordPress AI, Relume | 1시간 안에 랜딩 페이지(소개용 한 장짜리 페이지) |
| Lv2 AI 앱 빌더 (말로 시키면 앱을 통째로 만들어줌) | Lovable, v0, Bolt, Figma Make | 로그인·DB(데이터 저장소) 붙은 작은 웹앱 |
| Lv3 디자인→코드 | Figma Dev Mode(개발자용 모드) + MCP + AI 에디터 | 내 Figma 시안을 그대로 코드로 |
| Lv4 AI 코딩 에이전트 (코드를 직접 읽고 고치는 AI) | Claude Code, Cursor | Git 레포에서 기능 추가 → 커밋 → 푸시 |
| Lv5 배포·운영 | GitHub Pages / Vercel / Netlify (무료 사이트 공개 서비스), 도메인, 분석 툴 | 실제 운영 + 방문자 데이터 보기 |

> [!tip] projektory 활용
> 지금의 HTML/CSS/JS 연습 페이지 = Lv4~5 연습장. **"내 AI 작업물 포트폴리오 + 인스타 링크 허브"**(인스타 프로필 링크 하나로 내 모든 걸 보여주는 페이지)로 키우기.

### 1-3. 12주 커리큘럼 (주 6~8시간)

| 주차 | 배우기 | 만들기 (= 그대로 인스타 콘텐츠) |
|---|---|---|
| 1 | LLM(ChatGPT·Claude·Gemini 같은 대화형 AI의 엔진) 3종 비교, 프롬프트 구조 | 디자이너용 프롬프트 템플릿 10개 |

| 12 | 회고 + 케이스 스터디(문제→과정→결과 정리) | "12주 만에 디자이너가 AI 빌더 된 과정" 시리즈 |

## 2. 한국 대기업·IT 기업이 원하는 AI 역량

2026년 채용은 **"AI를 아느냐"가 아니라 "AI로 뭘 해냈느냐"**를 봄. 전문가 조사에서 *AI 이해·활용 능력 검증*이 채용 핵심 트렌드로 꼽혔고, 면접에서 "AI와 함께 뭘 할 수 있나요?"가 단골 질문. 대기업들은 사내 LLM(회사 안에서만 쓰는 자체 AI)을 운영함 — 삼성 Gauss, LG EXAONE, 네이버 HyperCLOVA X 등.

> [!warning] 참고
> 디자이너 직군만 따로 다룬 공개 자료는 못 찾아서, 아래 표는 일반 채용 트렌드 기반 **추정**이야. 실제 공고를 모아서 확인하는 게 제일 정확(→ 그 자체로 좋은 콘텐츠!).

| 기대 역량 | 증명 방법 |
|---|---|
| AI로 **속도·생산성** 올리기 | "시안 3일 → 1일" 같은 **Before/After 수치** |
| **AI로 프로토타입**(클릭되는 시안) 바로 만들기 | 정적 이미지 말고 실제 작동하는 링크 |
| **AI 서비스 UX**(사용자 경험) 설계 | 챗봇 화면, 프롬프트 입력창, AI가 틀렸을 때 화면 디자인 |
| 개발자·기획자와 **AI로 협업** | 디자인 시스템 토큰(색·글꼴·간격을 이름 붙여 관리하는 값), Figma→코드 경험 |
| **보안·윤리 감각** | 사내 데이터 외부 유출 금지, 저작권, AI 결과물 검수 기준 |
| **업무 자동화 제안** | 팀 반복 업무를 자동화한 사례 1개 |

### 커리어 체크리스트
- [ ] 포트폴리오에 **AI 케이스 스터디 3개** (문제 → AI 활용 과정 → 수치 결과)
- [ ] 직접 만들어 배포한 **웹사이트/웹앱 2개 이상**
- [ ] 자동화 워크플로 1개 (화면 녹화 포함)
- [ ] 이력서: "AI 툴 이름 나열" ❌ → **"AI로 무엇을 몇 % 개선"** ⭕
- [ ] 자격증·교육은 보조로만 (결과물을 대신 못 함)
- [ ] 인스타 계정 = **AI 실무 능력의 공개 증거** (회사 규정 확인 후)

## 3. 인스타 운영 전략

### 3-1. 포지셔닝 (나를 한 줄로 정의하기)
> **"AI로 직접 만드는 디자이너 — 따라 하면 나도 만들 수 있는 AI 활용법"**

- 타깃 1순위: 2030 디자이너·기획자·마케터 (일에 AI 쓰고 싶은 직장인)
- 타깃 2순위: 내 사이트/브랜드 갖고 싶은 비개발자 (1인 사업자, 프리랜서, 학생)
- 차별점: 정보만 전달하는 사람 ❌ **실제로 만드는 사람** ⭕ + 디자이너 감각
- 프로필: 이름에 키워드(예: `OO | AI 디자인·웹 제작`), 소개 한 줄에 "팔로우하면 뭘 얻는지", 링크는 projektory(링크 허브)

### 3-2. 콘텐츠 기둥 4개 (콘텐츠를 나누는 큰 주제와 비율)

| 기둥 | 비율 | 예시 | 노리는 지표 |
|---|---|---|---|
| **AI 실전 활용법** (튜토리얼 = 따라 하기 강좌) | 40% | "이 프롬프트로 무드보드 5분 완성" | 저장 |
| **AI로 웹사이트 만들기** (과정 공개) | 30% | "코딩 0으로 포트폴리오 사이트 EP.1~10", 타임랩스(빨리감기 영상) | 팔로우 |
| **툴 비교/리뷰** | 20% | "같은 프롬프트, 툴 3개 결과 비교" | 공유(DM 보내기) |
| **커리어·인사이트** | 10% | "대기업 디자이너 공고 AI 요구사항 분석", 실패담 | 댓글·신뢰 |

### 3-3. 포맷 & 빈도
- **릴스**(짧은 세로 영상) 주 2~3개 — 새로운 사람 데려오는 역할. **첫 1~2초에 결과물부터** ("이 사이트, 코딩 없이 30분 만에 만들었어요" = 후킹, 시선 잡는 첫마디). 화면 녹화 + 내 목소리/자막. 15~40초.
- **캐러셀**(옆으로 넘기는 여러 장 이미지) 주 1~2개 — 저장 담당. 7~10장. 1장 = 후킹 제목, 마지막 장 = CTA(행동 유도 문구: "저장하고 따라 해보세요") + 다음 편 예고. **디자이너 강점이 제일 잘 보이는 포맷** → 템플릿으로 통일감.
- **스토리**(24시간 뒤 사라지는 게시물) 매일 가볍게 — 작업 화면, 투표, 질문 박스로 다음 주제 아이디어 수집.
- **시리즈화**: EP.1, EP.2… 로 묶으면 "다음 편 보려고" 팔로우함.
- **시험용 릴스**(Trial Reels — 팔로워 말고 모르는 사람에게 먼저 보여줘서 반응 테스트하는 인스타 기능)로 새 포맷 실험.

### 3-4. 성장 단계

| 단계 | 팔로워 | 기간(예상) | 집중할 것 |
|---|---|---|---|
| 1 | 0 → 1천 | 1~3개월 | 게시물 30개로 실험. 뭐가 저장·공유되는지 찾기. 같은 분야 계정에 진심 담긴 댓글 |
| 2 | 1천 → 1만 | 3~8개월 | 잘 된 주제 시리즈화. **리드 마그넷**(무료 자료 주고 연락처 받기: 프롬프트 모음, 템플릿) → "댓글 남기면 DM" → 뉴스레터 모으기. **콜라보 게시물**(두 계정이 함께 올려 양쪽 팔로워에게 노출) |
| 3 | 1만 → 5만 | 8~18개월 | 대표 시리즈 2~3개 고정. 무료 라이브/워크숍, 스레드·유튜브 쇼츠로 재활용, 첫 수익화 |

> [!note] 현실 체크
> 5만은 보통 12~24개월짜리 목표. 바이럴(갑자기 크게 퍼지는 것) 1~2개가 단계를 건너뛰게 해주는데, 그건 꾸준히 올린 수십 개 중에서 나옴.

### 3-5. 매주 볼 숫자 (인스타 "인사이트" 메뉴에서 확인)

| 지표 | 의미 | 기준 |
|---|---|---|
| 저장 수 ÷ 도달(게시물을 본 사람 수) | 쓸모 있는 콘텐츠인가 | 캐러셀은 저장 > 좋아요면 성공 |
| 공유(보내기) 수 | 남에게 추천할 만한가 | 퍼지는 데 핵심 |
| 릴스 3초 유지율 / 평균 시청 시간 | 첫 장면이 먹혔나 | 첫 장면 고치는 게 효과 제일 큼 |
| 비팔로워 도달 비율 | 새 사람에게 퍼지고 있나 | 성장기엔 50% 이상 |
| 프로필 방문 → 팔로우 전환율 | 프로필이 설득력 있나 | 낮으면 프로필·고정 게시물 수정 |
| 링크 클릭 / 뉴스레터 가입 | 내 채널로 옮기고 있나 | 매주 증가 |

### 3-6. 주간 루틴 (주 7~10시간)

| 요일 | 할 일 | 시간 |
|---|---|---|
| 월 | 학습 + 작업 (화면 녹화 켜두기) | 2h |
| 화 | 릴스 1 편집·업로드 | 1h |
| 수 | 캐러셀 1 제작 (템플릿) | 1.5h |
| 목 | 학습 + 작업 | 1.5h |
| 금 | 릴스 2 업로드, 댓글·DM 답장 | 1h |
| 토 | 주간 지표 확인 → 다음 주 주제 3개 | 0.5h |
| 일 | 쉬기 (중요!) | — |

### 3-7. AI로 운영 자동화 (이것도 콘텐츠)
- 주제 리서치: AI에게 이번 주 AI 업데이트 요약 요청 → **원문 꼭 확인** (환각 주의)
- 대본: 작업하며 말한 녹음 → AI로 대본·자막 정리 (내 말투 유지)
- 캐러셀: Figma/Canva 템플릿 + AI로 문구 다듬기
- 재활용: 릴스 → 스레드 글 → 뉴스레터 → 사이트 블로그
- ⚠️ 전부 AI로 찍어내기 금지. 원본성과 사람 냄새가 핵심.
